Microsoft Corporation is a global enterprise software, cloud infrastructure, and personal computing company headquartered in Redmond, Washington. Its foundational software products include the Windows operating system, the Microsoft 365 productivity suite (Word, Excel, PowerPoint, Outlook, and Teams), and Dynamics 365 for enterprise resource planning and customer relationship management. For software developers, Microsoft owns GitHub and builds Visual Studio and Visual Studio Code.

Microsoft's Intelligent Cloud division is anchored by Microsoft Azure, one of the world's largest hyperscale cloud computing platforms. Azure provides virtual machines, managed databases, Kubernetes services, and Azure AI Studio for enterprise model deployment. Through its strategic partnership with OpenAI, Microsoft integrates frontier language models directly into its product ecosystem via Microsoft 365 Copilot and GitHub Copilot, enabling automated document drafting, spreadsheet analysis, and code generation.

In addition to enterprise software and cloud services, Microsoft competes in personal hardware and gaming. Its Surface lineup spans laptops and tablets built for Windows AI workflows, while its Xbox division encompasses gaming consoles, Xbox Game Pass subscriptions, and major game studios.
